# Web/H5 渲染规则（R-WEB）

> 触发条件：项目端矩阵含 Web 或 H5，且需求涉及页面渲染 / 性能。渲染指标缩写全称与一句话定义见文末术语表。落位字段含义见 SKILL.md 落位总表。

### R-WEB01 渲染按页面选
- 规则：按页面/区块的数据变化、SEO、首屏指标、部署与交互成本选渲染模式，允许同类页面共用一种模式；无 SEO 默认考虑 CSR，低频公开内容考虑 SSG/ISR，实时或个性化首屏可考虑 SSR。SEO 不是 SSR 的唯一理由；缓存须区分公开与用户数据，个性化响应默认 private/no-store，禁跨用户共享缓存。
- 落位：HLD·关键流程（Web 端）。
- 违反信号：未评估 SEO/指标/数据变化就定模式；无取舍依据推行全站统一或强制混用。

### R-WEB02 SSR 触发条件
- 规则：采用 SSR 须写明 SEO、首屏指标、弱设备或数据时效等具体收益，并评估服务端成本、hydration 与部署条件；缓存按数据敏感性和时效预算设计，公开数据可分层缓存，个性化/鉴权内容不强制 CDN 共享缓存。笼统性能要求高不能代替指标与实测依据。
- 落位：HLD·关键流程。
- 违反信号：无指标和收益依据选择 SSR；个性化数据进入未隔离的共享缓存。

### R-WEB03 混合渲染成本线
- 规则：优先复用既有渲染管线；少量低频公开页可预渲染，实时/个性化页是否 SSR 按收益评估。混合渲染须说明额外构建、部署、缓存与排障成本，页面数只能作估算输入，不能单独决定模式。
- 落位：HLD·关键流程。
- 违反信号：无收益或复用依据新增多套渲染管线。

### R-WEB04 区块级混用三细节
- 规则：静态内容与实时价格/库存分别声明取数和缓存策略；实时接口可用 no-store，公开展示价仅在业务允许的时效预算内短缓存，用户专属价格不得共享缓存。SEO 首屏需要价格时可服务端取数，不强制边缘子请求或固定 TTL。骨架保留内容尺寸防 CLS；下单由服务端复核最终价格与库存。
- 落位：HLD·关键流程；AGENTS.md（区块缓存策略）。
- 违反信号：价格缓存无时效/隔离规则；用户专属价格被共享缓存；展示缓存决定交易金额；占位与真值尺寸不符。

### R-WEB05 构建取数三禁令
- 规则：采用 SSG/ISR 时，跨服务取数走只读契约，不绕过数据所有权边界直连他方数据库；服务端同模块的受控数据访问按项目约定。长尾页是否按需生成须核对框架版本、路由模式与部署能力；Next.js Pages Router 的 fallback 与 App Router 的动态参数不是同一配置，静态导出不能默认具备运行时 ISR。取数失败须显式失败或走已定义的降级策略，禁静默发布空页；纯 SPA 无构建取数时不适用。
- 落位：HLD·关键流程；流水线·CI（构建失败即红）。
- 违反信号：跨服务直连数据库；未核对部署能力就承诺 ISR；取数失败被静默忽略。

### R-WEB06 组件归属规则
- 规则：仅在启用 React Server Components（如 Next.js App Router）的模块图中适用；`'use client'` 声明客户端边界，其静态导入也归客户端图，未写指令不代表一定在服务端。需状态、事件或浏览器 API 的组件放客户端边界，Server Component 禁用客户端 hooks/window，但可用框架允许的服务端 API。初始取数优先考虑服务端；客户端请求按交互、实时和离线需求论证。普通 React CSR、Pages Router、Vue/Nuxt 等不套用该指令规则。
- 落位：AGENTS.md。
- 违反信号：在非 RSC 框架强加该指令；混淆传递导入边界；Server Component 调客户端 hooks/window；取数位置无依据。

### R-WEB07 性能预算制
- 规则：按目标设备/网络与页面类型设 LCP/INP/CLS、体积等可测预算，实验室 CI 与线上分位数分开记录；LCP < 2.5s、JS < 200KB gzip 仅作起步参考，项目确认阈值与测量口径。优化依据 profile 与投入产出排序，不固定页面类型数量或手段先后。
- 落位：流水线·CI；HLD·性能。
- 违反信号：无预算红线；优化清单无优先级排序。

## 术语表（缩写 → 全称 → 一句话）

| 缩写 | 全称 | 一句话 |
|---|---|---|
| CSR | Client-Side Rendering（客户端渲染） | 服务器发空壳 HTML + JS，页面由浏览器 JS 生成 |
| SSR | Server-Side Rendering（服务端渲染） | 每个请求服务器现场生成完整 HTML |
| SSG | Static Site Generation（静态站点生成） | 构建时生成好全部 HTML，访问直接发文件 |
| ISR | Incremental Static Regeneration（增量静态再生） | SSG + 过期自动重做，重做期间先发旧版 |
| Hydration | 水合 | 客户端 JS 把事件装回静态 HTML、让页面"活过来"的过程 |
| SEO | Search Engine Optimization（搜索引擎优化） | 页面被搜索引擎抓取与排名的能力 |
| LCP | Largest Contentful Paint（最大内容绘制） | "看到内容"的时间指标 |
| TTI | Time to Interactive（可交互时间） | 页面"能点"的时间 |
| INP | Interaction to Next Paint（交互到下一次绘制） | "点了有反馈"的响应性指标 |
| CLS | Cumulative Layout Shift（累积布局偏移） | 页面元素"跳来跳去"的视觉稳定性指标 |
| TTL | Time To Live（缓存存活时长） | 缓存条目的有效期 |
