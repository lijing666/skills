# TDR（技术决策记录）模板

> 用途：跨端选型、共享技术栈引入/替换等重大技术决策的记录模板。TDR（Technical Decision Record，技术决策记录）是选型类 ADR 的内容模板，使用 ADR 编号与 `type: adr`；默认存放 `docs/adr/ADR-<编号>.md`，既有项目路径优先。退出条件提前写清何时重评、如何退出。本记录即该决策正源，不另建 TDR 目录或提炼第二份 ADR；HLD 引用该记录即可。仅咨询默认在回答中提供素材，需要保存时才创建文件。

```markdown
---
id: ADR-<编号>
title: <决策名> 技术决策记录
type: adr
status: proposed | accepted | superseded(→ADR-00xx)
date: YYYY-MM-DD
deciders: <参与决策人>
source: <本次咨询 / HLD 路径与版本>
approval: <待确认 / 有效决策评审记录>
---
```

填写纪律：

1. 投降条件 AI 可起草（标注假设），未确认的内容保持 proposed；accepted 依据当前工作流的有效决策批准/评审记录置位，不自批、不重复请求已有有效批准
2. 支持度类结论（"框架支持鸿蒙"）必须附官方来源链接，训练数据不作数
3. 决策状态变更（proposed → accepted → superseded）在本记录内演进；记录自身即决策正源，不另产出 ADR 副本
