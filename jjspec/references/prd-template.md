# PRD（需求文档）模板

> 用途：需求打磨阶段（所有需求的第一停靠点：大需求走完整打磨环，小需求走"直接开工"轻量 PRD 一轮确认）。撰写前必须先读 `prd-constitution.md`。
> 来源：用户《需求文档模板》（2026-09-23）通用化改编。
>
> **操作语义（AI 执行规则，与模板同等约束力）**
> - **落点**：进行中放 `changes/<需求ID>/prd.md`（本文件即 status 状态机载体）；**归档时**才经资产基线检查反馈到基线 `docs/PRD.md`，过程层原件随归档收进 `changes/archive/`——过程层不直接改资产层
> - **status 即状态机**：draft → 评审中 → 已定稿；跨会话续接靠本文件的 status + 附 D 待澄清清单，不靠会话记忆
> - **定稿只能由用户指令触发**：status 置"已定稿" + 版本表登记；AI 禁止自行定稿
> - **开工前校验（fail-closed）**：任何执行类指令（开工 / 拆 Spec / 写任务卡）先校验 status=已定稿，草稿/评审中一律拒绝并提示先定稿
> - **修订走版本表**：定稿后每次修订在版本表加一行并注明来源
