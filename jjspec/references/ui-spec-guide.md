# UI 规范生成与绑定管线

> 用途：「生成 UI 规范」与「绑定 UI 规范」两条触发指令的执行细则。前置规则（真源仲裁、原型冻结、前置产物四件套、双分支验收）见 `prd-constitution.md` 第九节，产物落点与命名见其第 10 条。
> 输入分支：HTML 原型（可实跑渲染）与设计稿（Figma 等，标注/API 导出）；两管线的前置产物四件套结构同构。

## 一、生成管线（触发词：生成 UI 规范 X，附视觉输入地址）

1. **判定输入分支**：HTML 原型 → 实跑渲染管线；设计稿（Figma 等）→ 消化提取管线。地址缺失或不可访问 → 停下询问，不猜测、不使用替代来源。
2. **机械提取**（禁止凭目测抄写）：
   - HTML 路线：Playwright（或等价工具）实跑原型，逐页采集 computed styles（颜色、字号、间距、圆角、阴影、布局尺寸）与 DOM 结构、图标位、文案；同视口、使用原型自带演示数据。
   - 设计稿路线：经设计稿标注、官方 API 或插件导出 Token、帧规格与切图；无法机械获取的项显式标注"人工补录"，不得编造。
3. **语义归并**（AI 参与的唯一环节）：聚类去重取值后语义命名 Token；图标位按语义指派图标（图标库优先，缺口导出 SVG 资产）；逐页产出页面布局规格（结构、间距、字号、状态；frontmatter 记录所属业务大项、关联 PRD 模块草案、视觉输入锚点）。
4. **落盘**：按宪法第九节第 10 条结构写 `ui-specs/<产品ID>-<业务大项>/`。`README.md` 登记来源（视觉输入路径与分支）、冻结哈希（HTML 路线 = 原型文件哈希；设计稿路线 = 四件套包 manifest 哈希，文件路径排序拼接后计算）、页面索引、未决项（空页面、状态缺口、人工补录项）。Token 实际扩展名（css/scss/json 按端框架）在 README 登记。**规范生成阶段不产出任何 baselines/**：HTML 路线的 `baselines/` 在实现阶段（D0/CI）由冻结原型实跑渲染生成（采集条件见宪法第九节第 5 条）；设计稿路线不产出 baselines，理由与导出帧处理见宪法第九节第 9 条（导出帧如需人工对照，另存实现工程内）。
5. **机械校验**：
   - Token 覆盖率：重扫视觉输入，≥95% 取值可映射到 Token，剩余登记例外清单；
   - 图标清点：视觉输入中图标位数量 = icons.json 条目数，无未指派位；
   - 页面清点：页面规格数与 README 索引一致，p-xx 编号无重号、无跳号（跳号须登记原因）。
6. **停靠**：输出对账清单（原始数据：逐项命中/未命中明细与计数，禁止只报结论）后停下，等用户确认。确认前 `README.md` 状态为 `draft`，确认后置为`可用`并记版本与日期。支持按业务大项增量生成（已有目录时增量合并，重号即失败）。

## 二、绑定管线（触发词：需求 X 与 UI 规范 Y 绑定）

1. **输入**：需求 PRD（识别是否分册）+ `ui-specs/<端>/`。规范缺失或 README 为 draft → 停下说明缺口。
2. **语义识别**（禁止名称字符串匹配）：逐页读 pages/*.md 的字段、操作、业务实体，对照 PRD 各 REQ 的名称、描述与验收场景，产出映射草案；每条映射必须附证据——页面字段/操作与 REQ 描述的具体对应点，可复核。
3. **分流**：
   - 证据充分且唯一 → 自动绑定；
   - 歧义 → 列入《待修正清单》逐条给出：跨模块页 / 一 REQ 对多页 / 页面找不到 REQ / REQ 找不到页面，等用户修正（可改、可补、可否决）。禁止静默绑定或静默丢弃。
4. **回填**：用户确认后一次性回填——全部 PRD 文件（含分册）第 8 章加「UI 真源」列（无 UI 对应的 REQ 填「—」、原型未绘制的空页面对应 REQ 填「空页面-新设计」）；主 PRD 加视觉真源绑定块（引用 ui-specs 路径与冻结哈希）；按宪法第九节第 8 条执行修订：版本 +1、回评审中、版本表登记修订来源。
5. **映射产物归档**：修正后的映射表收进 `changes/<需求ID>/`，标注"由 PRD 第 8 章生成，禁止手改"；PRD 第 8 章该列为唯一事实源。
6. **输出与停点**：输出绑定对账清单（自动绑定数 / 修正数 / 未匹配数及逐条明细），停在回填完成——不进入 Spec 或编码（开工仍需定稿有效与开工授权）。

## 三、红线

- 提取值与映射证据必须可追溯到视觉输入实况；禁止凭目测或记忆填数。
- 绑定不得静默：歧义必列、修正必等用户、回填必登记版本。
- 生成与绑定均为文档任务：不要求开工授权、不编码、不实施 AGENTS.md/CI 变更（执法规则建议只记录到产物中）。
- 本文件不改变既有的 PRD 状态机与定稿规则；绑定产生的 PRD 修订同样停在定稿前等用户指令。
