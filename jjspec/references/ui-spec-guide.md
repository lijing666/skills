# UI 规范生成与绑定管线

> 用途：「生成 UI 规范」与「绑定 UI 规范」两条触发指令的执行细则。前置规则（真源仲裁、原型冻结、前置产物四件套、双分支验收）见 `prd-constitution.md` 第九节，产物落点与命名见其第 10 条。
> 输入分支：HTML 原型（可实跑渲染）与设计稿（Figma 等，标注/API 导出）；两管线的前置产物四件套结构同构。

## 一、生成管线（触发词：生成 UI 规范 X，附视觉输入地址）

1. **判定输入分支**：HTML 原型 → 实跑渲染管线；设计稿（Figma 等）→ 消化提取管线。地址缺失或不可访问 → 停下询问，不猜测、不使用替代来源。
2. **机械提取**（禁止凭目测抄写）：
   - HTML 路线：Playwright（或等价工具）实跑原型，逐页采集 computed styles 与 DOM 结构、文案；同视口、使用原型自带演示数据。逐态采集：对视觉输入已覆盖的交互态（hover / focus / active / disabled 等以伪类/类名定义的态）逐一触发后采集该态样式；未覆盖态的处理见宪法第九节第 4 条（PRD 补规格）。默认单视口采集——原型含响应式断点时，断点清单与各断点取值差异登记 README 未决项，待用户确认，禁止静默丢弃非默认断点。
   - 设计稿路线：经设计稿标注、官方 API 或插件导出帧规格与切图；无法机械获取的项显式标注"人工补录"，不得编造。
   - **视觉物扫描（两分支共同，防类别遗漏的前提）**：机械扫描视觉输入中全部非文字视觉物，产出封闭的《视觉物候选清单》写入 `.extract/`——HTML 路线扫 img / background-image / canvas / 非图标 inline SVG / 图标字体节点（如 material-symbols-outlined 类文本节点：文字经图标字体渲染成图标，逐位计入图标位与 icons.json）/ CSS 渐变函数 / @font-face 字体文件引用；设计稿路线扫 IMAGE 填充、GRADIENT_* 填充、字体引用、exportSettings 节点。同一扫描同时产出 Token 原料取值（颜色、字号、字重、行高、字体族、间距、圆角、边框、阴影、透明度、渐变、布局尺寸、动效）。**候选清单条目数 = 步 5 素材处置对账的分母，禁止漏扫**。
3. **语义归并**（AI 参与的唯一环节）：
   - Token 归并按**封闭 15 类**登记：颜色、字号、字重、行高、字体族、间距、圆角、边框、阴影、透明度、渐变、布局尺寸、动效，另加图标、位图素材两类资产单列；**视觉输入确无该类取值时登记表填「无 + 理由」，禁止省略类别行**；取值归并：≥4 位小数或科学计数法取值（如 0.337812px、1.80823e+07px）为设计稿异常值，须归并到最近合理取值或转人工复核，禁止原样登记入 Token；
   - 素材处置：《视觉物候选清单》逐条四选一——token 化（渐变等可参数化项）/ 导出资产（位图与字体文件入 `assets/` 并登记 `assets.md`）/ 登记豁免（如 mock 演示图，写明理由）/ 标注人工补录（写明缺口；**仅限机械不可得项——可机械导出者不得标注人工补录**，如 Figma imageRef 须经官方 API 当场导出）；不留未处置条目。**视觉输入中可机械访问的素材必须当场处置完毕，禁止登记「留待实现」或以未决项替代处置**（未决项至多作附加说明，不消除处置义务）；**导出 = 复制入规范包 `assets/`，保证规范包自包含——页面卡实现 AI 只读消化规格、不回读原型取素材**，实现工程的资产引用方式由项目 AGENTS.md 声明（同宪法第九节第 10 条 tokens/icons 口径）；
   - 图标：图标位按语义指派图标（图标库优先，缺口导出 SVG 资产）——**HTML 与设计稿两分支都必须产出 icons.json**；
   - 逐页产出页面布局规格（结构、间距、字号、九态状态；frontmatter 记录所属业务大项、关联 PRD 模块草案、视觉输入锚点 source_anchor、**消化状态 `digest: list-level | quantified`**——list-level = 页面归属与变体帧已登记但布局未逐项量化；quantified = 间距/字号/层级/状态已逐项量化，可直接驱动页面还原与结构化断言，**其载体为页面内「## 节点样式量化表」段落——逐关键节点给位置尺寸/间距/字号字重↔文案映射/颜色圆角与 Token 名，频次统计（如 #000000(×19)）不构成量化**。清单级页只作映射与盘点用，**不得作为页面卡实现输入**，页面卡开工前须补消化至 quantified）。
4. **落盘**：按宪法第九节第 10 条结构写 `ui-specs/<产品ID>-<业务大项>/`。`README.md` 登记：来源（视觉输入路径与分支）、冻结哈希（HTML 路线 = 原型文件哈希；设计稿路线 = 四件套包 manifest 哈希，文件路径排序拼接后计算）、页面索引、未决项（空页面、状态缺口、人工补录项、响应式断点）、**资产类别登记表（15 类封闭，每类一行，处置 ∈ token化/icons.json/assets/无）**。资产处置=assets 时必含 `assets/assets.md`（位图与字体文件，条目含文件/类别/来源锚点/用途页面/处置，终态 ∈ 已导出/豁免/人工补录）。Token 实际扩展名（css/scss/json 按端框架）在 README 登记。HTML 路线**生成阶段产出 `baselines/`**——冻结哈希后的原型实跑渲染截图入库，作参考基准（采集条件见宪法第九节第 5 条）；实现阶段 pixel-diff 的执行环境与基准生成环境不同时，须以冻结原型在执行环境重产基准再对比（同环境渲染，防跨环境噪声淹没真实偏差）；设计稿路线不产出 baselines，理由与导出帧处理见宪法第九节第 9 条（导出帧如需人工对照，另存实现工程内）。
5. **机械校验**（全部通过才可停靠）：
   - **资产完整性门禁：运行 `assets/ui-pack-check.sh <目录>`，fail-closed**——15 类登记表齐全且处置合法、icons.json 存在且合法、素材清单无未终态条目、页面编号自 01 连续无重号、页面含 source_anchor；
   - Token 覆盖率：重扫视觉输入，≥95% 取值可映射到 Token，剩余登记例外清单；
   - 素材处置对账：视觉物候选条目数 = 素材清单条目数 + 豁免数 + 人工补录数，无未处置；
   - 图标清点：视觉输入中图标位数量 = icons.json 条目数，无未指派位；
   - 页面清点：页面规格数与 README 索引一致，p-xx 编号无重号、无跳号（跳号须登记原因）；
   - **页面消化门槛（按需启用）**：`ui-pack-check.sh <目录> --require-digest`（全部页须 quantified）或 `--require-digest p-<序号>`（仅校验指定页）——生成/补消化停靠时用全量模式；页面卡开工前按卡对应页用单页模式（门槛定义见 taskcard-template 拆卡规则 8）。
6. **停靠**：输出对账清单（原始数据：逐项命中/未命中明细与计数，禁止只报结论）后停下，等用户确认。确认前 `README.md` 状态为 `draft`，确认后置为`可用`并记版本与日期。支持按业务大项增量生成（已有目录时增量合并，重号即失败）。

## 二、绑定管线（触发词：需求 X 与 UI 规范 Y 绑定）

1. **输入**：需求 PRD（识别是否分册）+ `ui-specs/<端>/`。规范缺失或 README 为 draft → 停下说明缺口（用户显式授权跳过确认时，在续接区登记授权来源后放行）。
2. **语义识别**（禁止名称字符串匹配）：逐页读 pages/*.md 的字段、操作、业务实体，对照 PRD 各 REQ 的名称、描述与验收场景，产出映射草案；每条映射必须附证据——页面字段/操作与 REQ 描述的具体对应点，可复核。
3. **分流**：
   - 证据充分且唯一 → 自动绑定；
   - 歧义 → 列入《待修正清单》逐条给出：跨模块页 / 一 REQ 对多页 / 页面找不到 REQ / REQ 找不到页面，等用户修正（可改、可补、可否决）。禁止静默绑定或静默丢弃；用户指示"不确定项不绑定"时，全部记入映射产物的待修正区并填「—」。
4. **回填**：用户确认后一次性回填——全部 PRD 文件（含分册）第 8 章加「UI 真源」列（无 UI 对应的 REQ 填「—」、原型未绘制的空页面对应 REQ 填「空页面-新设计」、入口未达页填「待补占位」）；主 PRD 加视觉真源绑定块（引用 ui-specs 路径与冻结哈希）；按宪法第九节第 8 条执行修订：版本 +1、回评审中、版本表登记修订来源。
5. **映射产物归档**：修正后的映射表（**页面↔REQ↔素材三列**，素材列引用 `assets/assets.md` 条目或「—」）收进 `changes/<需求ID>/`，标注"由 PRD 第 8 章生成，禁止手改"；PRD 第 8 章该列为唯一事实源。
6. **输出与停点**：输出绑定对账清单（自动绑定数 / 修正数 / 未匹配数及逐条明细），停在回填完成——不进入 Spec 或编码（开工仍需定稿有效与开工授权）。

## 三、红线

- 提取值与映射证据必须可追溯到视觉输入实况；禁止凭目测或记忆填数。
- **视觉物候选未处置即失败、Token 类别行缺失即失败**——遗漏不允许"下次再补"（反模式见 `antipatterns.md` ⑨）。
- 绑定不得静默：歧义必列、修正必等用户、回填必登记版本。
- 生成与绑定均为文档任务：不要求开工授权、不编码、不实施 AGENTS.md/CI 变更（执法规则建议只记录到产物中）。
- 本文件不改变既有的 PRD 状态机与定稿规则；绑定产生的 PRD 修订同样停在定稿前等用户指令。
