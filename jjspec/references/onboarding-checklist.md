# 项目接入体检清单（Onboarding Checklist）

> 用途：新项目 / 新接手项目开工前 30 分钟的接入体检（九步 SOP 的前置，非场景编码任务）。体检产出《接入行动清单》，**P0 项完成前不进入任何 AI 编码任务**。

## 体检表

### A. L2 规则层（最优先）
| 检查项 | 判据 |
|---|---|
| 根级 AGENTS.md 存在？ | 无 → 用 assets/AGENTS.md.template 从零建（P0） |
| 内容质量？ | 六区块齐（身份/技术栈版本锁定/命令速查/R 规则/风险区/出错去哪查）？风险区清单带 risk-zones-begin/end 机器标记？规则有 R 编号 + 违反后果？行数 100~150 甜区？ |
| 双源风险？ | AGENTS.md 与 CLAUDE.md/.cursorrules 并存 → 收敛为单一事实源 + 单行指针（P0） |
| 模块级规则？ | 高风险模块（支付/鉴权）有无模块级 AGENTS.md？框架全局行为（ORM 租户过滤等）在**根级**（作用域定层级，不跟内容主题）？ |
| 内部框架盲区？ | 依赖内部 jar（训练数据没有 + 源码不在）→ 框架关键行为写进规则常驻；长尾进 L4 知识库 + 根级指针 |

### B. 门禁层
| 检查项 | 判据 |
|---|---|
| CI 存在？ | 无 → 至少先建：lint + 类型 + 单测三件套（P0） |
| 架构执法？ | 无 import-linter/ArchUnit/依赖规则 → 按 contract-toolbox 补（P1） |
| 越界检测？ | 无 → 装 assets/boundary-check.sh（P1） |
| 风险区门禁？ | 风险区清单非空而无门禁 → 装 assets/risk-zone-check.sh + `[risk-ok]` 约定（P1）——清单非空而门禁缺失 = AI 可擅改风险区 |
| 测试对应性检查？ | 改行为代码是否必须给出 AC↔测试对应（新增或引用既有+覆盖说明）？（P1） |
| 反馈速度？ | 单测能否秒级/分钟级跑完？不能 → AL2 模式暂不可用，先补 |

### C. 文档层（L3）
| 检查项 | 判据 |
|---|---|
| PRD/Spec？ | 需求是否只存在于对话/脑中 |
| HLD？ | 有无架构文档与风险节 |
| ADR 目录？ | docs/adr/ 存在？刻意设计有无留痕？ |

### D. 代码架构层
| 检查项 | 判据 |
|---|---|
| 反模式扫描 | 按 antipatterns.md 八项打勾（上帝类：Top 文件行数；utils：数量与职责；静态可变状态；循环依赖） |
| 测试覆盖比 | 测试文件数 / 源文件数——**快速粗筛信号**（文件数 ≠ 断言覆盖）：<10% 触发深入检查，实际跑测试看通过数与断言质量；目标模块级先达 40%+ |
| 变更聚簇 | Git 历史抽查：功能 commit 平均跨几个顶层模块（≥3 = 边界切错嫌疑） |

### E. 回流层
| 检查项 | 判据 |
|---|---|
| 知识回流机制 | AI 出错有无归因回流的固定动作与模板？（无 → 装 feedback-loop.md） |

### F. 安全部（AI 协作特有红线）
| 检查项 | 判据 |
|---|---|
| 密钥扫描进 CI？ | 无 gitleaks/trufflehog 之类扫描 → 补（P1）——AI 硬编码密钥、生成"格式像密钥的字符串"人眼难辨，必须机器扫 |
| 依赖变更审查？ | 依赖清单（package.json / pom.xml / pyproject.toml 等）未设 PR 必审 → 配 CODEOWNERS（P1）——防 Agent 顺手装包（投毒包 / 传染协议 / 带 CVE 版本混在几百行 diff 里） |
| 数据分级×模型位置矩阵？ | 未定义"哪些数据允许进哪类模型（本地/私有化/公有云）" → 架构师定矩阵写进 AGENTS.md（P1，**人的决策项非 AI 自查项**）——没有矩阵时，每次请求都在隐性做合规决策 |

## 行动清单模板

```markdown
## 《<项目名> 接入行动清单》YYYY-MM-DD
| 优先级 | 行动 | 产物 |
|---|---|---|
| P0 | 建根级 AGENTS.md（六区块，R 编号） | AGENTS.md |
| P0 | CLAUDE.md 收敛为单行指针 | CLAUDE.md = 1 行 |
| P1 | CI 补越界检测 + 测试对应性检查 | ci.yml 修订 |
| P1 | CI 补密钥扫描 + 依赖清单必审配置 + 数据分级矩阵 | ci.yml + CODEOWNERS + AGENTS.md |
| P1 | 风险区门禁进 CI（risk-zone-check.sh + [risk-ok] 约定） | ci.yml 增补 |
| P1 | 高风险模块补模块级 AGENTS.md | modules/payment/AGENTS.md |
| P2 | import-linter 契约 ×3 | pyproject 增补 |
```
