# HLD 注入契约（hld-injection）

> 用途：模式 A 产出注入时执行。注入不改 jjspec HLD 模板骨架——只在既有章节内追加带标注的子块；未命中的槽位不注入。所有注入子块首行标 `<!-- jjagent 命中层:<层名> 规则:<R-AGxx 清单> -->`。

## 槽位映射（对齐 jjspec hld-template.md 的章节名）

| HLD 章节 | 注入内容 | 规则 |
|---|---|---|
| §1 设计概览 | 确定性/概率分工裁决表：环节 × 实现方式（代码/LLM）× 校验方式 | R-AG01 |
| §3 接口设计 | LLM 节点契约：每节点模型/参数表（机械任务关 reasoning）、结构化输出 schema、意图分类 max_tokens 预算、入模字段白名单 | R-AG12 / R-AG29 / R-AG23 |
| §4 数据变更 | 任务状态表（含恢复方式声明）、幂等缓存键 = 内容哈希、审计独立表落位 | R-AG06 / R-AG24 / R-AG27 / R-AG31 |
| §5 关键流程 | 状态机与确认闸门清单、守墓人参数（心跳/倍数阈值/重放语义）、流式协议（事件/状态分离 + `\n\n` 缓冲切分 + 重连先订阅后拉快照）、限流实现与扩展信号 | R-AG07 / R-AG10 / R-AG16 / R-AG17 / R-AG18 / R-AG15 / R-AG08 |
| §6 风险与开放问题 | 期权清单（用 `assets/options-ledger-template.md`）：行权信号+前提+成本 | R-AG02 |
| §7 技术选型 | 供应商/网关选型：配置灵活性、连通性验活、网关三权边界；多端触达时端选型走 jjfullstack 选型程序，勿在此重复出题 | R-AG11 / R-AG14 |

## 执行留痕（硬要求）

产出 HLD 须附：

1. 命中层判定输入——本次需求触达了哪些 Agent 产线要素
2. 所引规则 ID 清单——含每条适用前提是否成立的判断
3. 注入子块数量与位置

无留痕 = 标称失准 = 未执行（与 jjspec 方案三查「查方向」的标称拦截对齐）。

## 与 jjfullstack 同时命中

各自按契约注入、各自标注、互不改模板骨架；落位重叠时（如同一条 AGENTS.md 约束双方都要求）去重合并，保留双 ID 注记（如 `<!-- jjagent R-AG11 + jjfullstack R-Uxx -->`）。
