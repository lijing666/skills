# Golden Set 评测集（golden-set）

> 落点：项目 tests/golden/（或项目约定位置）。机制（两级门阈值/谁校验校验者/选集纪律）见 jjagent `rules/quality-obs.md` R-AG19/R-AG03 与当前工作流的评估体系——本模板只承载数据。

## 单条 case 结构

```yaml
id: G-<序号>
输入: <原始输入或引用文件>
期望: <期望输出或判定要点>
归一化: <比对前如何归一（排序/去空白/键集合等）>
来源: 历史成功 | ⚠️ 历史失败 | ⚠️ 构造
备注: <可选>
```

## 建集纪律

- 必须收录模型曾失败过的 case（最贵的测试用例）；构造场景标注 ⚠️ 构造，随真实失败逐步替换
- 期望变更走人审（谁校验校验者）——先区分测试错还是程序错，拿不准列待人工，不代裁
- 两级门分离：确定性逻辑 Mock 100% / 真 LLM 评测 95% 报警不阻塞——不混一门
- 耗尽型 Mock 桩：mock 数据用尽必须报错，禁静默兜底造成假通过
