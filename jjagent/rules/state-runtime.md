# 任务运行时（state-runtime）

> 适用范围：Agent 产品的任务执行、异步处理、部署演进相关设计；与 universal 叠加取并集。

## R-AG06 状态外置与写序

- **规则**：任务状态住数据库不驻内存——进程重启后可从库续接；状态更新先写库后发响应（含事件推送），两步不可倒置。
- **适用前提**：异步任务/长耗时操作/需要重启续接的任务流。
- **落位**：HLD 数据变更节（状态表 schema + 恢复方式）；AGENTS.md 条目。
- **违反信号**：内存 dict/单例持有任务状态；响应发出后才落库；重启丢任务。

## R-AG07 守墓人判死

- **规则**：进程死亡与任务挂起统一用单一超时阈值判死（心跳超过 3× 周期未续即判死），判死后触发重放/清理；禁止为两种死法各建一套检测。
- **适用前提**：存在可重放的任务执行体。
- **落位**：HLD 关键流程节（守墓人参数：心跳周期、倍数阈值、重放语义）。
- **违反信号**：双套判死逻辑；无扫描器（任务卡死无人收尸）；阈值无心跳倍数依据。

## R-AG08 扩展阶梯

- **规则**：加机器前先审判状态外置度——内存态/本地文件态未外置，扩容只会放大问题；DB-as-queue、外部队列、pub/sub 按 R-AG02 期权信号升级，不预先引入。
- **适用前提**：部署形态从单实例向多 worker/多实例演进时。
- **落位**：HLD 关键流程节（扩展触发信号）；期权清单。
- **违反信号**：单机内存态直接上多 worker；无信号预建 Redis/Celery。

## R-AG09 约束求解分级

- **规则**：约束满足类任务（分组/排班/匹配）全员建模不抽样，由求解器保证可行性与冲突检测；规模超过显式定义的切换边界时用精确求解器（CP-SAT 类），小场用贪心+局部搜索；切换边界必须显式定义并挂 R-AG02 期权。
- **适用前提**：任务本质是约束满足/组合优化，非自由文本生成。
- **落位**：HLD 关键流程节（边界值 + 两套算法选择）；求解器选型 ADR。
- **违反信号**：抽样+事后修补；边界未定义；小场直接上求解器。

## R-AG10 人类在环闸门

- **规则**：错误代价大（不可逆/大量资源浪费/外部副作用）的下游动作保留确认步骤；低风险路径提供自动通过开关；闸门位置在不可逆动作之前而非之后。
- **适用前提**：任务流含高危下游动作。
- **落位**：HLD 关键流程节（闸门清单：哪些动作、谁批、超时语义）；AGENTS.md 条目。
- **违反信号**：全自动无闸门直通不可逆动作；全人工无开关导致吞吐为零；闸门设在动作已执行后。
