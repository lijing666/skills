# RAG 与工具（rag-tools）

> 适用范围：检索增强、外部工具调用、结构化输出、文档导入管线相关设计。

## R-AG28 Embedding 单例同模

- **规则**：Embedding 模型全局初始化一次复用（禁每请求加载）；向量入库与检索必须同一模型——换模型即全量重建，不得混用检索。
- **适用前提**：使用向量检索（RAG/语义搜索）。
- **落位**：代码（全局单例）；模型版本登记 ADR。
- **违反信号**：每次请求重新加载模型；存取两端模型版本不一致。

## R-AG29 结构化输出校验

- **规则**：LLM 结构化输出必须过 schema 校验（pydantic/等价）+ 错误路径显式后才可使用；禁裸 json.loads 信任。校验失败走 R-AG04 拒绝出口。
- **适用前提**：LLM 输出被程序消费（JSON/工具参数）。
- **落位**：HLD 接口设计节；AGENTS.md 条目。
- **违反信号**：直接解析不校验；校验失败静默重试或吞掉。

## R-AG30 工具分级

- **规则**：外部工具调用按副作用分级——写/删/资金/外发等高危工具默认人工确认 + 参数白名单；只读低危工具可自动执行；分级清单显式维护，不靠模型自行判断危险性。
- **适用前提**：Agent 具备工具调用能力。
- **落位**：HLD 关键流程节（工具分级表，与 R-AG10 闸门共用机制）。
- **违反信号**：全工具自动执行；高危工具无确认；分级靠口头约定无清单。

## R-AG31 内容哈希去重

- **规则**：文档导入管线按文件内容哈希判重——相同内容跳过 chunk 切分与向量计算；禁按文件名/mtime 判重。
- **适用前提**：文档增量导入/重复导入场景。
- **落位**：管线代码（缓存键）；AGENTS.md 条目。
- **违反信号**：重复文档重复入库；mtime 变化即重算。
