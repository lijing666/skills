# LLM 接入层（llm-gateway）

> 适用范围：任何 LLM 调用的配置、成本、供应商治理设计；Agent 需求默认命中本层。

## R-AG11 配置灵活与启动验活

- **规则**：base_url、api_key、model 必须可配置（env/配置文件），密钥禁入镜像与仓库；启动或首次调用做连通性验证，失败时给出可读错误（端点/鉴权/模型名分类），禁止裸超时堆栈暴露给上层。
- **适用前提**：任何 LLM 调用接入。
- **落位**：HLD 接口设计节（配置 schema）；AGENTS.md 条目。
- **违反信号**：供应商 SDK 直连硬编码；key 出现在代码/Dockerfile；配置错误排障靠读堆栈。

## R-AG12 机械任务成本工程

- **规则**：评分/抽取/分类等机械任务必须关闭 reasoning（或等价降参）、用低温、压 max_tokens；意图分类等短输出节点的 max_tokens 必须给足——截断会造成静默误分类。不同节点允许不同模型与参数（强模型做解码、经济模型做评分）。
- **适用前提**：任务可判定为机械型（输入输出形态可枚举、无需多步推理）。
- **落位**：HLD 接口设计节（节点参数表）；AGENTS.md 条目。
- **违反信号**：思考模型跑机械评分（token 与延迟数量级超标）；分类节点输出被截断仍被解析。

## R-AG13 参数自动降级且降级可见

- **规则**：OpenAI 兼容端点拒绝非核心参数（400/422）时自动剥参重试；每次降级必须上报（日志/指标）——静默降级视同缺陷，降级成功的监控盲区必须显式覆盖。
- **适用前提**：使用 OpenAI 兼容 API 且使用非核心参数（reasoning_effort 等）。
- **落位**：HLD 关键流程节；日志字段定义。
- **违反信号**：非核心参数导致整链路失败；降级无痕迹可查。

## R-AG14 网关三权

- **规则**：供应商路由（选择权）、熔断降级（止损权）、成本账本（知情权）集中在网关层（模块即可，不必独立服务）；业务代码禁直连供应商 SDK。第二供应商+熔断按 R-AG02 期权信号引入。
- **适用前提**：LLM 调用点多于一个，或存在成本/可用性治理诉求。
- **落位**：HLD 接口设计节（网关模块边界）；AGENTS.md 条目。
- **违反信号**：业务模块散装 import 供应商 SDK；无成本账本；熔断缺失且无期权挂账。

## R-AG15 限流两界

- **规则**：多 worker/多实例部署禁用进程内存限流（限值按实例数翻倍失真）——用 Redis 原子计数或网关层限流；窗口算法用滑动窗口，固定窗口有边界突发问题。上游 429 是闭环控制信号：接到即降速，不是错误重试。
- **适用前提**：存在限流需求且部署形态为多 worker/多实例，或调用外部有配额的 API。
- **落位**：HLD 关键流程节；AGENTS.md 条目。
- **违反信号**：内存计数器 + uvicorn --workers N；固定窗口限流；把 429 当 5xx 重试。
